# 개인 담당 분석 노트북

- **[Activation.ipynb](Activation.ipynb)** — 2023년 5월 48시간 Activation 사용자 추출, 초기 Vote 강도·지속성 기준 비교, 4개 행동 세그먼트 생성, 세그먼트별 W1~W8 Retention 분석, 지속성과 후속 Retention 간 카이제곱 검정

이 노트북은 팀 프로젝트 중 개인이 담당한 분석 코드를 정리한 것입니다. 분석용 CSV(`valid_vote_daily.csv`, `user_activation_retention.csv`, `vote_event_analysis.csv`)는 기업 내부 자료이므로 포함하지 않습니다. 노트북의 저장된 결과는 집계 수준으로 표시되며, 원본 CSV가 없어 재실행 검증은 수행하지 않았습니다.
